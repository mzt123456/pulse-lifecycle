# 数据口径与权限

## 统计口径

| 名词 | 口径 |
| --- | --- |
| 低库存耗材 | 当前库存 ≤ 安全库存 |
| 待维保设备 | 非报废、累计使用时长 ≥ 500 小时，且最近维保时间超过 90 天或从未维保 |
| 未解决故障 | 处理状态不等于"已解决" |
| 设备利用率 | 区间内使用时长 ÷ 区间总小时数 |

## 权限点

工具只对持有对应权限点的账号暴露，权限点与页面菜单一致：

| 数据 | 权限点 |
| --- | --- |
| 整体概览 | `report.view` |
| 设备台账 | `equipment.view` |
| 故障记录 | `fault.view` |
| 维保工单 | `maintenance.view` |
| 耗材库存 | `consumable.view` |
| 使用记录 | `well_operation.view` |

只读用户持有上述只读权限，因此可以做数据问答但不能新增或修改。
若用户问的是自己没有权限的数据，正确做法是告诉他去联系管理员，而不是解释表结构。
